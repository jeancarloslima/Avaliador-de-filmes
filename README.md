# 🎬 Avaliador de Filmes

Um projeto React de avaliação de filmes para um recomendador de filmes. Onde o usuário recebe uma série de filmes e avalia para definir o gosto inicial dele.

## 💻 Sobre o Projeto

Este projeto foi construído para ser uma ferramenta dinâmica de registo de resenhas e notas, inspirado na dinâmica de plataformas como o Letterboxd, com foco em componentes acessíveis do React Aria Components.

## ✨ Funcionalidades

- Sistema de Avaliação (Star Rating).
- Cards de Avaliação.
- Modais Interativos.
- Design Responsivo e Moderno.

## 🛠️ Tecnologias Utilizadas

- **[Vite]** - Ferramenta de build
- **[React]** - Biblioteca principal
- **[Tailwind CSS]** - Estilização responsiva e moderna
- **[React Aria Components]** - Componentes acessíveis

## 🔗 Acesse o Projeto

- https://avaliador-de-filmes-iota.vercel.app/

## 🚀 Como executar localmente

1. Clone o repositório:
`git clone https://github.com/jeancarloslima/Avaliador-de-filmes.git`
2. Acesse à pasta do projeto:
`cd Avaliador-de-filmes`
3. Instale as dependências:
`npm install`
4. Inicie o ambiente de desenvolvimento:
`npm run dev`
